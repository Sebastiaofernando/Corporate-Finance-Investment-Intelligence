# Corporate-Finance-Investment-Intelligence

Projeto de Portfólio desenvolvido em PlanMaker com foco em análise financeira, contabilidade, investimentos e visualização de dados.

O objetivo é transformar bases de dados financeiras em indicadores de desempenho e informações que apoiem a análise empresarial  e de investimentos.

## AVISO: este projeto utiliza dados fictícios para fins educacionais. Os valores não representam demonstrações financeiras oficiais, cotações reais da B3 nem recomendações de investimentos.

# OBJETIVOS DO PROJETO
-Desenvolver competências práticas em excel aplicado às finanças;
-Organizar e relacionar bases de dados empresariais e financeiras;
-Calcular indicadores de desempenho financeiro;
-Analisar demonstrações financeiras e uma carteira de investimentos simulada;
-Construir um dashboard para facilitar a interpretação dos resultados;
-Demonstrar competências analíticas relevantes para oportunidades nas áreas de Finanças, Contabilidade e Dados;

# FERRAMENTAS UTILIZADAS

2 - Referências entre planilhas

4 - Indicadores financeiros
5 - Gráficos e dashboards
6 - Git e GitHub para documentação e versionamento do projeto

# ESTRUTURA DO PROJETO
O ficheiro excel está organizado nas seguintes abas:

# ABA                # DESCRIÇÃO
Base_Empresas              Cadastro e identificação das empresas
Base_Ativos                Cadastro dos ativos da carteira
Precos_Mercado             Histórico de preços simulados dos ativos
Movimentos_Investimentos   Registo de compras e vendas simuladas
Carteira_Investimentos     Posições, quantidades, preços e resultados da carteira
Base_DRE                   Demonstração do resultado do exercício
Base_DP                    Dados do balanço patrimonial
Base_DFC                   Demonstração dos fluxos de caixa
Indicadores                Consolidação dos indicadores financeiros
Dashboard                  Apresentação visual dos principais resultados

# INDICADORES FINANCEIROS
O projeto contempla o cálculo e a análise dos seguintes indicadores:

- Receita líquida total
- Lucro líquido total
- Fluxo de caixa líquido
- Ativos totais
- Passivos totais
- Património líquido
- Margem operacional consolidada
- Margem líquida consolidada
- Rentabilidade simplificada da carteira
- Relação entre ativos e passivos
- Número de empresas com lucro positivo
- Número de empresa com fluxo de caixa positivo
